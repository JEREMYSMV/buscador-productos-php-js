# Buscador de Productos con PHP y JavaScript

Proyecto académico desarrollado para aplicar conocimientos de PHP, JavaScript, HTML, CSS y MySQL.

## Descripción

Aplicación web que permite buscar, filtrar y visualizar productos mediante una interfaz dinámica.

## Funcionalidades

- Búsqueda de productos por nombre.
- Filtrado por categorías.
- Filtrado por precio y disponibilidad.
- Paginación de resultados.
- Visualización de imágenes y detalles.
- Consultas a MySQL mediante PHP.

## Tecnologías

- PHP
- JavaScript
- HTML5
- CSS3
- MySQL
- XAMPP

## Instalación

1. Instalar XAMPP.
2. Copiar el proyecto a `htdocs`.
3. Iniciar Apache y MySQL.
4. Importar la base de datos desde phpMyAdmin.
5. Configurar la conexión local a MySQL.
6. Abrir el proyecto desde localhost.

## Objetivo

Demostrar conocimientos de PHP y JavaScript
mediante una aplicación web que integra
frontend, backend y base de datos.
